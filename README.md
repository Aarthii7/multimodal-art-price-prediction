# Multimodal Art Price Prediction

## Description
This project focuses on predicting artwork prices using a multimodal deep learning framework. The system combines image features, textual descriptions, and metadata from auction market datasets to improve prediction accuracy through multimodal fusion techniques.

## Technologies Used
- Python
- PyTorch
- Torchvision
- Pandas
- NumPy
- Scikit-learn
- EfficientNet-B0
- Jupyter Notebook

## Features
- Image feature extraction
- Text and metadata processing
- Multimodal data fusion
- Deep learning-based price prediction
- Data preprocessing and analysis
- Model training and evaluation

## Project Outcome
Developed a data-efficient multimodal framework capable of predicting artwork prices using combined visual and textual information from auction market datasets.
